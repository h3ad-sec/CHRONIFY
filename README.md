# CHRONIFY

Forensic timestamp converter, part of [H3AD-SEC](https://h3ad-sec.github.io)'s H3AD-DF module.

Converts between the timestamp formats commonly encountered in DFIR work: Unix (seconds/milliseconds), Windows FILETIME, Chrome/WebKit, Mac Absolute Time, HFS+/classic Mac OS, DOS Date/Time (FAT/ZIP), OLE Automation Date, and ISO 8601 (UTC/local). Edit any field and every other format updates instantly.

Client-side only, no backend, no data leaves the browser.

Live at: https://h3ad-sec.github.io/CHRONIFY/
